# Inbox live acceptance run — October 2026

All three live cases passed with Claude Code 2.1.296, Node 26.5.0, a Linux
service and an Android/Termux phone over private-tailnet HTTPS. Phone answer and
defer ran on 2026-10-12 in America/New_York (EDT, UTC−04:00), which was
2026-10-13 UTC. Desk withdrawal ran on 2026-10-13 in both timezones.

## Isolation and route verification

The service and hooks ran from the task worktree by explicit executable paths.
A private scratch directory held a separate 0700 relay state directory, scratch
workspace, generated settings and empty subscriber configuration. The settings
were generated by `relay install --harness claude-code --with ask` with the
answer-route evidence, then reduced to the two AskUserQuestion hooks:
PreToolUse with handback and PostToolUse confirmation. Presence was set to away.

Claude started with a clean environment, private Claude and XDG directories,
`--setting-sources ''`, explicit `--settings`, strict empty MCP configuration
and only the AskUserQuestion tool. Its actual arguments, environment and trust
were checked. Runtime `get_settings` and `get_hooks_listing` confirmed exactly
two enabled startup hooks with no disabling policy; the live cases confirmed
their execution. The real relay state and real Claude settings were not altered.

With the user's authorization, temporary Tailscale Serve HTTPS on port 8443
forwarded to `127.0.0.1:3341`. The phone's inbox GET returned HTTP 200 before
the cases. Phone POSTs used the HTTPS origin including port 8443 and also
returned HTTP 200.

## Observed transitions

These offsets come from the durable entry logs, measured from each question's
creation timestamp. They include manual setup, waiting and selection; they are
not network latency or unattended service benchmarks. The native observations
and the user's final Claude output corroborate the saved states.

**Phone answer:** the phone selected Square. Handback occurred 15 ms after the
server saved the answer, and consumption was confirmed 166 ms after it saved
the answer. The user confirmed Claude's final reply was `CHOSEN=Square`.
The point read retained the entry in `consumed` state.

**Phone defer:** the phone deferred the new question, and the native question
appeared in the terminal. The user selected Square there and confirmed Claude's
reply was `chosen=square`. The native observation was saved 86,025 ms after
the phone defer, including manual terminal selection. The entry stayed
`released` with the native answer recorded.

**Desk withdrawal:** `relay inbox withdraw` exited 0. The entry recorded
`withdrawn` with durable reason `user`, and the waiting hook exited. The user
confirmed their last Claude output included the PreToolUse hook error
`question withdrawn by the user; do not wait for an answer`, followed by a
statement that the hook had withdrawn the question and no choice was available.
No replacement inbox question was seen in a 60,041 ms observation window after
withdrawal. This is a bounded observation, not a guarantee against later re-asks.

## Deviations and restoration

The three case outcomes matched expectations. Setup and inspection differed in
the following ways:

- Claude's `/hooks` menu omitted hooks supplied through `--settings`. Actual
  startup configuration and runtime hook listings supplied the verification
  above. The inspection friction is recorded as `hq-da1015`; no upstream fix
  is claimed.
- At the user's request, the initial one-hour service window was renewed to
  two hours. Both completed entries were recovered after service restarts.
  During an AFK pause the service stopped and the temporary mapping was removed;
  the same isolated state resumed for the withdrawal case.
- The default inbox collection excludes terminal entries. Point reads and
  `?since=0` exposed their retained history.
- Tailscale warned of a client/daemon version mismatch. The actual phone HTTPS
  GET and POST requests nevertheless returned HTTP 200.

The temporary HTTPS 8443 mapping was removed with
`tailscale serve --https=8443 off`; existing HTTPS 443 service was retained.
All test service and observation processes were stopped and reaped, and the
isolated Claude process and its ask hooks were confirmed gone. The test HTTP
port was closed. Private evidence was retained outside git; this record omits
session, call, question, answer and process identifiers, hostnames and login
details.
