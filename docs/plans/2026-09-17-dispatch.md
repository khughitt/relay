# Bounded Guard and Observer Dispatch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Status:** draft for user review, 2026-09-17. Nothing below has been implemented.

**Goal:** Complete `relay-4c4828`: `relay hook` reads one native hook payload, runs
configured guards first, publishes the registry, notifies observers, and answers the
harness in its verified native reply protocol, all inside one monotonic budget; and
`relay reap` notifies reconciliation observers.

**Architecture:** Four small modules on top of R1. `adapters/reply.js` owns the
standard decision model both Claude Code and Codex document and each adapter
declares which native events can refuse or carry context. `subscribers.js` owns the
executable configuration file, its validation, event matching and the budget
profile. `child.js` runs one subscriber without a shell, capped and killable.
`dispatch.js` sequences guards, registry and observers under one deadline and
converts every failure it survives into a refusal on refusal-capable events.

**Tech Stack:** Node >=22, ES modules, Node built-ins, `node:test`, Just and the
vendored ops timing/check tools. No runtime or development dependency.

**Spec:** ops `docs/specs/2026-09-16-relay-design.md` §4-§7 (approved after
`d7e2c33`), the R2 brief in ops `docs/plans/2026-09-16-relay-bootstrap.md`, and
R1's contract in `docs/api.md`. The native reply and timeout facts below were
verified on 2026-09-17 against the current
[Claude hooks reference](https://code.claude.com/docs/en/hooks) and
[Codex hooks reference](https://developers.openai.com/codex/hooks).

## Global constraints

- Work in `.worktrees/relay-4c4828/` on branch `relay-4c4828`. `tasks check` before
  every commit; conventional commits; no AI attribution.
- Node built-ins only. No daemon, retry queue, socket, event archive or background
  work. No installer, no live hook/plugin registration, no remote, no tag.
- R1's contracts are unchanged: schema-1 `Snapshot`, `Agent`, `Handle`, `Event`,
  the closed event table, `paths()`, `applyEvent`, `reapRegistry` and all error codes.
  `protocol.js` gains only the exported `KINDS` list.
- Guards run before optional enrichment (git, process, registry) and observers.
  A valid guard result is never discarded because observation failed. Once any
  guard denies, no registry or observer work runs before the denial is returned.
- **Fail closed for configured guards, only for failures relay survives:** guard
  timeout, spawn failure, nonzero exit, invalid or oversized reply, unsupported
  channel, invalid configuration, malformed input or an expired deadline produce a
  native refusal on refusal-capable events. Missing Node, an early crash, and the
  harness's outer timeout are documented and tested as outside that promise.
- Native input <=4 MiB (R1). Subscriber stdout and stderr <=64 KiB each; more is an
  explicit error. Reply `reason` and `context` <=10,000 characters each and combined
  context <=10,000 characters; oversize is an error, never truncation.
- Subscribers run with `shell: false` and inherit the hook environment unchanged.
  No environment value is copied into any envelope, registry file, stdout or stderr.
  Full tool input reaches only guards matched on `before-tool`; observers receive
  the tool name only.
- Native stdout is exclusively relay's reply. Subscriber stdout is captured and, for
  observers, discarded. Subscriber stderr becomes relay stderr diagnostics only on
  exit-0 replies; a refusal's stderr is exactly the reason.
- Budgets are monotonic (`performance.now`) and shared by input, subscribers,
  registry and reply. Worst-match configuration is validated on every load.
- Codex `Interrupt` stays unmapped (`UNSUPPORTED_EVENT`). OpenCode has no reply
  channels: guards cannot target it.

## Verified native facts this plan relies on

| Fact | Claude Code | Codex |
| --- | --- | --- |
| PreToolUse deny | `{"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"…"}}` | identical |
| PreToolUse context | `hookSpecificOutput.additionalContext` | identical |
| UserPromptSubmit block | top-level `{"decision":"block","reason":"…"}`; context via `hookSpecificOutput.additionalContext` | identical |
| Stop continuation | top-level `{"decision":"block","reason":"…"}`, reason required | identical; the reason becomes the continuation prompt |
| Exit 2 + stderr | blocks PreToolUse, UserPromptSubmit and Stop even alongside JSON; JSON reason wins over stderr | documented for the same three events |
| Notification, SessionStart, SessionEnd, StopFailure | no decision control | SessionEnd advisory; PermissionRequest uses a different `decision.behavior` object, unexposed in v1 |
| Output size | hook strings capped at 10,000 characters, spilled to a file | ~2,500 tokens spilled to a file; `additionalContextLimit` per handler |
| Outer timeout defaults | 600 s; 30 s for UserPromptSubmit; SessionEnd shares 1.5 s, raised to the per-hook `timeout` up to 60 s | 600 s; SessionEnd and Interrupt 1 s default, 3 s maximum |
| Timeout effect | output discarded; PreToolUse proceeds through normal permission flow | reported as hook failure; tool call continues |
| Startup failure | exit 127 style, non-blocking notice, action proceeds | hook failure, action proceeds |

A live probe (`ops-c8e4d1`) must still confirm the installed versions honor these;
this plan only implements and tests the encoders against these fixtures.

## Decisions the brief left to this plan

1. **Subscriber configuration** (`$XDG_CONFIG_HOME/relay/subscribers.json`, 0700 dir,
   0600 file, owned by the invoking user; an absent file means no subscribers,
   anything unreadable, unsafe or invalid is `INVALID_CONFIG`):

   ```json
   {
     "schema": 1,
     "subscribers": [
       { "name": "ops-guard", "role": "guard", "kinds": ["before-tool"],
         "harnesses": ["claude-code", "codex"], "tools": ["Bash"],
         "argv": ["/usr/bin/python3", "/abs/path/hooks/relay-guard"], "timeoutMs": 4000 },
       { "name": "familiar", "role": "observer",
         "kinds": ["session-start", "prompt", "before-tool", "activity", "idle", "needs-input",
                   "needs-approval", "turn-end", "turn-error", "reconcile"],
         "argv": ["/abs/path/familiar/bin/familiar", "observe"], "timeoutMs": 2000 },
       { "name": "familiar-teardown", "role": "observer", "kinds": ["session-end"],
         "argv": ["/abs/path/familiar/bin/familiar", "observe"], "timeoutMs": 200 }
     ]
   }
   ```

   Teardown is its own subscription because Codex `SessionEnd` admits 267 ms of
   subscriber time at its 1 s default and 800 ms at its 3 s cap (Decision 2); a 2 s
   observer on `session-end` would fail validation and no SessionEnd would publish.
   The installer should set Codex `SessionEnd` to its 3000 ms cap and Claude's
   `SessionEnd` per-hook `timeout` to match, and validate this file against both.

   `name` matches `^[a-z0-9][a-z0-9-]{0,63}$` and is unique. `kinds` is a nonempty
   unique subset of the ten event kinds; observers may add the pseudo-kind
   `reconcile`. `harnesses` is optional for observers and required for guards; every
   guard `(kind, harness)` pair must map to native events that all have a refusal
   channel. `tools` is allowed only when `kinds` is exactly `["before-tool"]`.
   `argv[0]` is absolute; `timeoutMs` is an integer in 1..60000. Unknown fields are
   errors.
2. **Budget source.** `relay hook --harness NAME [--outer-ms H] EVENT`; the installer
   (`relay-baa816`) passes the same `H` it writes as the harness `timeout`. Without
   the flag relay uses the documented default for that harness/event. Relay never
   plans beyond 60 s regardless of `H`, rejects `H` above a documented cap (Codex
   SessionEnd 3000, Claude SessionEnd 60000) and below 500 ms, and derives one
   profile from the effective `H`:

   | Component | Rule | H=1000 | H=1500 | H=30000 | H>=60000 |
   | --- | --- | --- | --- | --- | --- |
   | margin | clamp(H/10, 100, 5000) | 100 | 150 | 3000 | 5000 |
   | reserve (termination + reply) | clamp(H/10, 100, 1000) | 100 | 150 | 1000 | 1000 |
   | input | min(5000, H/5) | 200 | 300 | 5000 | 5000 |
   | registry | min(12000, H/3) | 333 | 500 | 10000 | 12000 |
   | total (relay deadline) | H - margin | 900 | 1350 | 27000 | 55000 |
   | subscribers (sum of matching timeouts) | total - input - registry - reserve | 267 | 400 | 11000 | 37000 |

   Worst match = every subscriber whose `kinds` contains the event kind and whose
   `harnesses` admits the harness, ignoring the tool filter. Its timeout sum must fit
   `subscribers`, checked on every load and exported for the installer.
3. **Guard protocol.** stdin: `{"schema":1,"type":"event","subscriber":"<name>","event":<Event>}`
   with the full `Event` including `tool.input`. stdout: one JSON object
   `{"decision":"allow"|"deny","reason"?,"context"?}`; `deny` requires `reason`;
   unknown fields are errors; exit code must be 0. All matching guards run in
   configuration order even after a denial (the spec's literal wording; the
   alternative of stopping at the first denial was rejected because the extra cost
   is bounded by the validated budget and later guards keep seeing the attempt).
   The first denial's reason is the reply; a denial with `context` drops the context.
   A guard error is a refusal with reason `relay refused: <CODE>: <message>`.
4. **Observer envelope** (stdin; observers' stdout is discarded):
   `{"schema":1,"type":"event"|"reconcile","subscriber":"<name>","event":<Event with tool reduced to {name}>|null,"registry":{"generation":string|null,"revision":number|null},"changed":boolean,"reaped":string[]}`.
   Observers run only after a successful registry publication (changed or not) or a
   reap; after a registry failure they are skipped with a diagnostic and healed by
   reconciliation. `type: "reconcile"` carries `event: null`.
5. **Exit codes of `relay hook`.** 0 for an allow reply (with or without context);
   2 with the JSON refusal on stdout and the reason on stderr for any refusal;
   1 with a `CODE: message` line for an error on an event without a refusal
   channel, and for an allow reply whose registry publication failed (the harness
   shows a non-blocking notice; the guard result stands). Observer failures never
   change the exit code; they are stderr diagnostics.
6. **Child termination.** SIGKILL at the child's bound (`min(timeoutMs, remaining)`),
   destroy the pipes, then wait at most 200 ms for `close` before giving up on the
   handle. A child ignoring SIGKILL is an OS stall covered by the survival limitation.
7. **Filesystem work is bounded by the same deadline.** R1's `readJson`,
   `writeJsonAtomic` and `checkPrivate` do not consult the deadline (only lock waits,
   git and process reads do), so `dispatchHook` races config loading, publication and
   reap against the remaining budget with `bounded(thunk, {clock, deadline})`, which
   rejects `DEADLINE_EXCEEDED` and leaves the I/O to finish or fail on its own. An
   expired config load is a refusal; an expired publication is a registry diagnostic
   on an allow reply, with observers skipped. Because a pending fs operation keeps
   Node's event loop alive, `bin/relay.js` flushes its reply through write callbacks
   and then calls `process.exit(code)` explicitly. A publication abandoned mid-lock
   leaves a token whose holder is dead; R1's reclaim path recovers it on the next write.

No spec addendum is needed: these are the contracts the R2 brief asked the plan to
nail down, and they extend rather than change the approved design.

// src/adapters/reply.js
import { relayError } from '../protocol.js';
// Claude Code caps hook strings at 10,000 characters and Codex spills large output to a
// file (both references checked 2026-09-17). Relay treats more as an error, never truncation.
export const CONTEXT_LIMIT = 10000;
const NONE = Object.freeze({ refuse: false, context: false });
const FIELDS = ['decision', 'reason', 'context'];
const object = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);
const text = (v) => typeof v === 'string' && v.trim().length > 0;
const fail = (message, cause) => { throw relayError('INVALID_REPLY', message, cause); };
export function parseReply(output, { limit = CONTEXT_LIMIT } = {}) {
  let value;
  try { value = JSON.parse(output); } catch (cause) { fail('subscriber reply is not JSON', cause); }
  if (!object(value)) fail('subscriber reply must be a JSON object');
  const extra = Object.keys(value).find((k) => !FIELDS.includes(k));
  if (extra !== undefined) fail(`unexpected reply field ${extra}`);
  if (!['allow', 'deny'].includes(value.decision)) fail('reply decision must be allow or deny');
  for (const field of ['reason', 'context']) {
    if (Object.hasOwn(value, field) && (!text(value[field]) || value[field].length > limit)) fail(`reply ${field} must be nonempty text of at most ${limit} characters`);
  }
  if (value.decision === 'deny' && !Object.hasOwn(value, 'reason')) fail('a denial requires a reason');
  return { decision: value.decision, ...(Object.hasOwn(value, 'reason') ? { reason: value.reason } : {}),
    ...(Object.hasOwn(value, 'context') ? { context: value.context } : {}) };
}
// The standard decision model both Claude Code and Codex document: PreToolUse answers inside
// hookSpecificOutput; UserPromptSubmit and Stop use top-level decision/reason. A refusal is
// written as JSON and as exit 2 with the reason on stderr, which both harnesses honor together.
export function encodeStandardReply(nativeEvent, reply, capability = NONE) {
  const line = (v) => `${JSON.stringify(v)}\n`;
  if (reply.decision === 'deny') {
    if (!capability.refuse) throw relayError('UNSUPPORTED_REPLY', `${nativeEvent} has no refusal channel`);
    const stdout = nativeEvent === 'PreToolUse'
      ? line({ hookSpecificOutput: { hookEventName: 'PreToolUse', permissionDecision: 'deny', permissionDecisionReason: reply.reason } })
      : line({ decision: 'block', reason: reply.reason });
    return { stdout, stderr: `${reply.reason}\n`, exitCode: 2 };
  }
  if (reply.context === undefined) return { stdout: '', stderr: '', exitCode: 0 };
  if (!capability.context) throw relayError('UNSUPPORTED_REPLY', `${nativeEvent} has no context channel`);
  return { stdout: line({ hookSpecificOutput: { hookEventName: nativeEvent, additionalContext: reply.context } }), stderr: '', exitCode: 0 };
}

import * as fs from 'node:fs/promises';
import { isAbsolute } from 'node:path';
import { relayError, KINDS } from './protocol.js';
import { adapterFor } from './adapters/index.js';
import { checkPrivate } from './bus/store.js';
export const RECONCILE = 'reconcile';
const HARNESSES = ['claude-code', 'codex', 'opencode'];
const FIELDS = ['name', 'role', 'kinds', 'harnesses', 'tools', 'argv', 'timeoutMs'];
const MAX_TIMEOUT_MS = 60000, MAX_PLANNED_MS = 60000, MIN_OUTER_MS = 500, INPUT_MS = 5000, REGISTRY_MS = 12000;
const fail = (message, cause) => { throw relayError('INVALID_CONFIG', message, cause); };
const object = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);
const text = (v) => typeof v === 'string' && v.trim().length > 0;
const list = (v, ok) => Array.isArray(v) && v.length > 0 && new Set(v).size === v.length && v.every(ok);
const clamp = (v, lo, hi) => Math.min(hi, Math.max(lo, v));
const nativeEventsFor = (harness, kind) => Object.entries(adapterFor(harness).events).filter(([, e]) => e.kind === kind).map(([name]) => name);
function validateSubscriber(v, index) {
  if (!object(v)) fail(`subscriber ${index} must be an object`);
  const where = `subscriber ${JSON.stringify(v.name ?? index)}`;
  if (typeof v.name !== 'string' || !/^[a-z0-9][a-z0-9-]{0,63}$/.test(v.name)) fail(`${where}: name must match [a-z0-9][a-z0-9-]{0,63}`);
  if (!['guard', 'observer'].includes(v.role)) fail(`${where}: role must be guard or observer`);
  const kinds = v.role === 'observer' ? [...KINDS, RECONCILE] : KINDS;
  if (!list(v.kinds, (k) => kinds.includes(k))) fail(`${where}: kinds must be a nonempty unique list of event kinds`);
  const harnesses = v.harnesses ?? null, tools = v.tools ?? null;
  if (harnesses !== null && !list(harnesses, (h) => HARNESSES.includes(h))) fail(`${where}: harnesses must be a nonempty unique list of harness names`);
  if (v.role === 'guard' && harnesses === null) fail(`${where}: a guard must name its harnesses`);
  if (tools !== null && !list(tools, text)) fail(`${where}: tools must be a nonempty unique list of tool names`);
  if (tools !== null && !(v.kinds.length === 1 && v.kinds[0] === 'before-tool')) fail(`${where}: a tools filter requires kinds exactly ["before-tool"]`);
  if (!Array.isArray(v.argv) || !v.argv.length || !v.argv.every((a) => typeof a === 'string') || !isAbsolute(v.argv[0])) fail(`${where}: argv must be strings starting with an absolute executable`);
  if (!Number.isInteger(v.timeoutMs) || v.timeoutMs < 1 || v.timeoutMs > MAX_TIMEOUT_MS) fail(`${where}: timeoutMs must be an integer from 1 to ${MAX_TIMEOUT_MS}`);
  const extra = Object.keys(v).find((k) => !FIELDS.includes(k));
  if (extra !== undefined) fail(`${where}: unexpected field ${extra}`);
  if (v.role === 'guard') {
    for (const harness of harnesses) for (const kind of v.kinds) {
      const natives = nativeEventsFor(harness, kind);
      if (!natives.length || !natives.every((n) => adapterFor(harness).replies[n]?.refuse)) fail(`${where}: ${harness} ${kind} has no refusal channel`);
    }
  }
  return { name: v.name, role: v.role, kinds: [...v.kinds], harnesses: harnesses && [...harnesses], tools: tools && [...tools], argv: [...v.argv], timeoutMs: v.timeoutMs };
}
export function validateSubscribers(v) {
  if (!object(v) || v.schema !== 1 || !Array.isArray(v.subscribers)) fail('subscriber config must be {"schema":1,"subscribers":[...]}');
  const subscribers = v.subscribers.map(validateSubscriber);
  if (new Set(subscribers.map((s) => s.name)).size !== subscribers.length) fail('subscriber names must be unique');
  return { schema: 1, subscribers };
}
// Repository files and hook payloads cannot register executables: only a privately owned
// 0600 file inside a 0700 relay config directory is read. Absent means no subscribers.
export async function loadSubscribers(paths, { io = fs } = {}) {
  let present;
  try { present = await checkPrivate(paths.configDir, true, { io }) && await checkPrivate(paths.subscribersPath, false, { io }); }
  catch (cause) { fail('subscriber config must be a privately owned 0600 file in a 0700 directory', cause); }
  if (!present) return { schema: 1, subscribers: [] };
  let value;
  try { value = JSON.parse(await io.readFile(paths.subscribersPath, 'utf8')); }
  catch (cause) { fail('cannot read subscriber config JSON', cause); }
  return validateSubscribers(value);
}
const admits = (s, harness) => harness === null || s.harnesses === null || s.harnesses.includes(harness);
export function matchSubscribers(config, event) {
  return config.subscribers.filter((s) => s.kinds.includes(event.kind) && admits(s, event.harness)
    && (s.tools === null || (event.tool !== null && s.tools.includes(event.tool.name))));
}
export const matchReconcile = (config) => config.subscribers.filter((s) => s.role === 'observer' && s.kinds.includes(RECONCILE));
// One profile per outer timeout H: relay plans at most 60 s inside it, keeps a margin below
// H and a reserve for termination and the reply, and bounds input and registry work.
export function budgetFor({ harness = null, nativeEvent = null, outerMs } = {}) {
  let max = Infinity;
  if (harness !== null) {
    const adapter = adapterFor(harness);
    adapter.stateForEvent(nativeEvent);
    outerMs ??= adapter.outerTimeouts[nativeEvent] ?? adapter.outerTimeouts.default;
    max = adapter.outerTimeouts.max[nativeEvent] ?? Infinity;
  }
  if (!Number.isInteger(outerMs) || outerMs < MIN_OUTER_MS) throw relayError('USAGE', `outer timeout must be an integer of at least ${MIN_OUTER_MS} milliseconds`);
  if (outerMs > max) throw relayError('USAGE', `${harness} ${nativeEvent} allows at most ${max} milliseconds`);
  const effective = Math.min(outerMs, MAX_PLANNED_MS);
  const marginMs = clamp(Math.floor(effective / 10), 100, 5000), reserveMs = clamp(Math.floor(effective / 10), 100, 1000);
  const inputMs = Math.min(INPUT_MS, Math.floor(effective / 5)), registryMs = Math.min(REGISTRY_MS, Math.floor(effective / 3));
  const totalMs = effective - marginMs;
  return { outerMs, totalMs, inputMs, registryMs, reserveMs, marginMs, subscribersMs: totalMs - inputMs - registryMs - reserveMs };
}
// Worst match ignores tool filters: the installer and every load reject configuration whose
// matching timeouts cannot all fit.
export function checkBudget(config, budget, { harness = null, kind }) {
  const matching = config.subscribers.filter((s) => s.kinds.includes(kind) && admits(s, harness));
  const need = matching.reduce((sum, s) => sum + s.timeoutMs, 0), fit = Math.max(0, budget.subscribersMs);
  if (need > fit) fail(`subscribers for ${harness ?? 'reconcile'} ${kind} need ${need} ms but ${fit} ms fit inside ${budget.outerMs} ms`);
  return matching;
}

import { spawn } from 'node:child_process';
export const OUTPUT_LIMIT = 64 * 1024;
// Runs one subscriber directly: no shell, the hook environment inherited untouched (no env
// option), stdin fed once, stdout/stderr each capped. It resolves a status instead of
// throwing so the dispatcher can classify a failure without losing partial output.
export function runChild(argv, input, { clock = performance.now.bind(performance), deadline, timeoutMs, spawnFn = spawn, limit = OUTPUT_LIMIT, graceMs = 200 } = {}) {
  const allowed = Math.min(timeoutMs, deadline - clock());
  if (allowed <= 0) return Promise.resolve({ status: 'timeout', exitCode: null, signal: null, stdout: '', stderr: '' });
  return new Promise((resolve) => {
    let child;
    try { child = spawnFn(argv[0], argv.slice(1), { shell: false, stdio: ['pipe', 'pipe', 'pipe'] }); }
    catch (error) { resolve({ status: 'spawn-failed', exitCode: null, signal: null, stdout: '', stderr: '', error }); return; }
    const out = { chunks: [], bytes: 0 }, err = { chunks: [], bytes: 0 };
    let status = 'exited', error, settled = false, grace;
    const finish = (exitCode, signal) => {
      if (settled) return;
      settled = true; clearTimeout(timer); clearTimeout(grace);
      resolve({ status, exitCode, signal, stdout: Buffer.concat(out.chunks).toString('utf8'), stderr: Buffer.concat(err.chunks).toString('utf8'), ...(error ? { error } : {}) });
    };
    const abort = (why, cause) => {
      if (status !== 'exited') return;
      status = why; error = cause;
      child.kill('SIGKILL');
      for (const stream of [child.stdin, child.stdout, child.stderr]) stream?.destroy();
      grace = setTimeout(() => finish(null, 'SIGKILL'), graceMs);
    };
    const collect = (sink) => (chunk) => { sink.chunks.push(chunk); sink.bytes += chunk.length; if (sink.bytes > limit) abort('output-exceeded'); };
    const timer = setTimeout(() => abort('timeout'), allowed);
    child.stdout.on('data', collect(out)); child.stderr.on('data', collect(err));
    child.once('error', (cause) => { abort('spawn-failed', cause); finish(null, null); });
    child.once('close', (code, signal) => finish(code, signal));
    child.stdin.on('error', () => {}); // an early exit closes stdin; the exit status is the useful signal
    child.stdin.end(input);
  });
}

import { adapterFor, normalizeEvent } from './adapters/index.js';
import { readNativeInput } from './adapters/payload.js';
import { parseReply, CONTEXT_LIMIT } from './adapters/reply.js';
import { paths as defaultPaths } from './bus/paths.js';
import { applyEvent, reapRegistry } from './bus/transaction.js';
import { relayError } from './protocol.js';
import { loadSubscribers, matchSubscribers, checkBudget, budgetFor, RECONCILE } from './subscribers.js';
import { runChild } from './child.js';

const NONE = Object.freeze({ refuse: false, context: false });
const describe = (error) => `${error.code ?? 'IO_ERROR'}: ${error.code ? error.message : 'relay failed'}`;
const lines = (list) => list.map((l) => `${l}\n`).join('');
// R1's filesystem operations do not consult the deadline. This races a unit of work against
// the remaining budget; the work itself is left to finish or fail on its own.
export function bounded(thunk, { clock, deadline }, message) {
  const remaining = deadline - clock();
  if (remaining <= 0) return Promise.reject(relayError('DEADLINE_EXCEEDED', message));
  return new Promise((resolve, reject) => {
    const timer = setTimeout(() => reject(relayError('DEADLINE_EXCEEDED', message)), remaining);
    thunk().then((value) => { clearTimeout(timer); resolve(value); }, (error) => { clearTimeout(timer); reject(error); });
  });
}
// Observers see identity and event metadata plus the published generation/revision; the
// tool is reduced to its name. Reconciliation carries no event at all.
export function envelope(type, subscriber, event, result) {
  return { schema: 1, type, subscriber: subscriber.name,
    event: event === null ? null : { ...event, tool: event.tool === null ? null : { name: event.tool.name } },
    registry: { generation: result.snapshot?.generation ?? null, revision: result.snapshot?.revision ?? null },
    changed: result.changed, reaped: result.reaped };
}
export async function runObservers(observers, inputFor, { clock, workDeadline, run }, diagnostics) {
  for (const observer of observers) {
    if (clock() + observer.timeoutMs > workDeadline) { diagnostics.push(`SUBSCRIBER_SKIPPED: ${observer.name} does not fit the remaining budget`); continue; }
    const result = await run(observer.argv, JSON.stringify(inputFor(observer)), { clock, deadline: workDeadline, timeoutMs: observer.timeoutMs });
    if (result.status !== 'exited' || result.exitCode !== 0) diagnostics.push(`SUBSCRIBER_FAILED: ${observer.name} ${result.status}${result.exitCode === null ? '' : ` exit ${result.exitCode}`}`);
    for (const line of result.stderr.split('\n').filter(Boolean)) diagnostics.push(`${observer.name}: ${line}`);
  }
}
async function runGuards(guards, event, capability, { clock, workDeadline, run }, diagnostics) {
  const contexts = []; let denial = null, error = null;
  for (const guard of guards) {
    if (clock() >= workDeadline) { error ??= relayError('DEADLINE_EXCEEDED', `guard ${guard.name} did not start before the deadline`); break; }
    const result = await run(guard.argv, JSON.stringify({ schema: 1, type: 'event', subscriber: guard.name, event }), { clock, deadline: workDeadline, timeoutMs: guard.timeoutMs });
    try {
      if (result.status !== 'exited') throw relayError('GUARD_FAILED', `guard ${guard.name} ${result.status}`);
      if (result.exitCode !== 0) throw relayError('GUARD_FAILED', `guard ${guard.name} exited ${result.exitCode}`);
      let reply;
      try { reply = parseReply(result.stdout); } catch (cause) { throw relayError(cause.code, `guard ${guard.name}: ${cause.message}`, cause); }
      // A denial is complete with its reason; context on a denial is dropped, so the channel
      // check applies only to allow replies.
      if (reply.decision === 'deny') denial ??= reply.reason;
      else if (reply.context !== undefined) {
        if (!capability.context) throw relayError('UNSUPPORTED_REPLY', `guard ${guard.name} returned context on an event without a context channel`);
        contexts.push(reply.context);
      }
    } catch (cause) { error ??= cause; }
    for (const line of result.stderr.split('\n').filter(Boolean)) diagnostics.push(`${guard.name}: ${line}`);
  }
  const context = contexts.join('\n');
  if (!error && context.length > CONTEXT_LIMIT) error = relayError('UNSUPPORTED_REPLY', `combined context exceeds ${CONTEXT_LIMIT} characters`);
  return { denial, error, context };
}
export async function dispatchHook({ harness, nativeEvent, input, outerMs }, deps = {}) {
  const clock = deps.clock ?? performance.now.bind(performance), start = clock();
  const { loadConfig = loadSubscribers, run = runChild, apply = applyEvent, readInput = readNativeInput, applyOptions = {} } = deps;
  const failure = (error) => ({ stdout: '', stderr: `${describe(error)}\n`, exitCode: 1 });
  let adapter, budget;
  try { adapter = adapterFor(harness); adapter.stateForEvent(nativeEvent); budget = budgetFor({ harness, nativeEvent, outerMs }); }
  catch (error) { return failure(error); }
  const capability = adapter.replies[nativeEvent] ?? NONE;
  const refuse = (reason) => adapter.encodeReply(nativeEvent, { decision: 'deny', reason });
  // Fail closed for configured guards: any failure relay survives becomes a native refusal
  // where one exists; elsewhere it is reported because no refusal channel can be manufactured.
  const abort = (error) => capability.refuse ? refuse(`relay refused: ${describe(error)}`) : failure(error);
  const workDeadline = start + budget.totalMs - budget.reserveMs, diagnostics = [];
  let paths, event, guards, observers;
  try {
    paths = deps.paths ?? defaultPaths(deps.env ?? process.env);
    const config = await bounded(() => loadConfig(paths), { clock, deadline: workDeadline }, 'subscriber configuration did not load before the deadline');
    checkBudget(config, budget, { harness, kind: adapter.events[nativeEvent].kind });
    const raw = await readInput(input, { clock, deadline: Math.min(workDeadline, start + budget.inputMs) });
    event = normalizeEvent(harness, nativeEvent, raw);
    const matching = matchSubscribers(config, event);
    guards = matching.filter((s) => s.role === 'guard'); observers = matching.filter((s) => s.role === 'observer');
  } catch (error) { return abort(error); }
  const { denial, error, context } = await runGuards(guards, event, capability, { clock, workDeadline, run }, diagnostics);
  if (denial !== null) return refuse(denial);
  if (error) return abort(error);
  let result = null;
  try {
    const deadline = Math.min(workDeadline, clock() + budget.registryMs);
    result = await bounded(() => apply(event, { ...applyOptions, paths, clock, deadline }), { clock, deadline }, 'registry publication did not finish before the deadline');
    for (const d of result.diagnostics) diagnostics.push(`${d.code}: ${d.message}${d.agentId ? ` (${d.agentId})` : ''}`);
  } catch (cause) { diagnostics.push(`registry: ${describe(cause)}`); }
  if (result === null) for (const o of observers) diagnostics.push(`SUBSCRIBER_SKIPPED: ${o.name} skipped after registry failure`);
  else await runObservers(observers, (o) => envelope('event', o, event, result), { clock, workDeadline, run }, diagnostics);
  const reply = adapter.encodeReply(nativeEvent, context ? { decision: 'allow', context } : { decision: 'allow' });
  return { stdout: reply.stdout, stderr: lines(diagnostics), exitCode: result === null ? 1 : reply.exitCode };
}

// relay reap: prune confirmed deaths, publish if changed, then tell reconcile observers to
// reread the snapshot. No event is fabricated and no guard runs. Loading and reaping errors
// propagate so the CLI reports them; observer failures are diagnostics.
export async function reconcile({ outerMs = 30000 } = {}, deps = {}) {
  const clock = deps.clock ?? performance.now.bind(performance), start = clock();
  const { loadConfig = loadSubscribers, run = runChild, reap = reapRegistry } = deps, paths = deps.paths ?? defaultPaths();
  const budget = budgetFor({ outerMs }), workDeadline = start + budget.totalMs - budget.reserveMs, diagnostics = [];
  const config = await bounded(() => loadConfig(paths), { clock, deadline: workDeadline }, 'subscriber configuration did not load before the deadline');
  const observers = checkBudget(config, budget, { kind: RECONCILE });
  const deadline = Math.min(workDeadline, clock() + budget.registryMs);
  const result = await bounded(() => reap({ paths, clock, deadline }), { clock, deadline }, 'registry reap did not finish before the deadline');
  await runObservers(observers, (o) => envelope('reconcile', o, null, result), { clock, workDeadline, run }, diagnostics);
  return { result, diagnostics };
}

const usage = (message) => relayError('USAGE', message);
// Strict flag parsing: --harness NAME (hook only), --outer-ms N, then exactly one EVENT for hook.
function parse(args, { harness }) {
  const out = {}, rest = [];
  for (let i = 0; i < args.length; i += 1) {
    if (args[i] === '--outer-ms' || (harness && args[i] === '--harness')) {
      const key = args[i] === '--harness' ? 'harness' : 'outerMs';
      if (i + 1 >= args.length || Object.hasOwn(out, key)) throw usage(`${args[i]} needs one value`);
      out[key] = args[i + 1]; i += 1;
    } else rest.push(args[i]);
  }
  if (Object.hasOwn(out, 'outerMs')) { if (!/^[1-9][0-9]*$/.test(out.outerMs)) throw usage('--outer-ms must be a positive integer'); out.outerMs = Number(out.outerMs); }
  if (harness) { if (!out.harness) throw usage('hook requires --harness NAME'); if (rest.length !== 1) throw usage('hook requires exactly one EVENT'); out.nativeEvent = rest[0]; }

  return out;
}

// asynchronous on Darwin, and a pending filesystem operation would otherwise keep the
// process alive past the harness's outer timeout.
const emit = (stream, text) => new Promise((resolve) => (text ? stream.write(text, () => resolve()) : resolve()));
export async function main(args, { list = listAgents, reap = reconcile, hook = dispatchHook, stdin = process.stdin, stdout = process.stdout, stderr = process.stderr } = {}) {
