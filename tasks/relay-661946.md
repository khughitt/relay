Mac attempt 2 of the Darwin probe: D8's hook_path renders the PreToolUse command with relay's planHooks and runs it under PATH=/usr/bin:/bin:/usr/sbin:/sbin (what a GUI-launched harness inherits from launchd). It failed with 'env: node: No such file or directory' (exit 127), so the guard never ran: the command runs bin/relay.js through its '#!/usr/bin/env node' shebang, and node from nvm or Homebrew is not on launchd's PATH. Fix: render the absolute node path (the installer's process.execPath) in front of relay.js in every hook command, with a test that runs the rendered command under a minimal PATH. Cutover evidence for ai-539508 (launchd-path).
